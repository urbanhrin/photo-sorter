# 사진 정리

안드로이드용 사진·동영상 정리 앱. 인터넷 권한이 없고, 모든 동작이 휴대폰 안에서만 일어난다.

## 설치

1. 이 저장소의 **Releases**에서 최신 `photo-sorter.apk`를 휴대폰으로 받는다.
2. 받은 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용한다.
3. 처음 실행할 때 사진·동영상 접근을 **모두 허용**한다.

코드를 고쳐서 `main`에 올리면 GitHub Actions가 새 APK를 자동으로 만든다. 같은 키로 서명하므로 기존 앱 위에 덮어 설치하면 정리 기록이 유지된다.

## 동작

- 날짜별로 묶어서 보여주고, 사진과 동영상은 탭으로 나뉜다.
- 필터: 전체 / 스크린샷(동영상은 화면 녹화) / 연사
- 한 장씩 크게 보면서 왼쪽으로 밀면 지우기, 오른쪽으로 밀면 남기기. 되돌리기 가능.
- 비슷한 사진: 1초 안에 연달아 찍은 사진을 한 묶음으로 본다(촬영 시각만 사용, `Media.kt`의 `SIMILAR_GAP_MS`).
- 고른 결과와 보던 날짜는 휴대폰 안에 저장되어, 다음에 열면 이어서 정리한다.
- 실제 삭제는 "지울 항목 확인" 화면에서 한꺼번에 한다. 안드로이드 휴지통으로 보내므로 30일 안에 되살릴 수 있다.

안드로이드 8 이상에서 동작한다. 안드로이드 10 이하는 시스템 휴지통이 없어 바로 영구 삭제된다(확인 창을 한 번 더 띄운다).
